OVERVIEW: Builds a report from a run's results file, or from its shards'
results files merged.

USAGE: swift-mutator report <results> ... [--format <format>] [--output <output>] [--fail-under <percent>] [--property-tests <glob> ...] [--force-merge] [--merge-ignoring <glob> ...] [--summary <path>] [--triage <path>]

ARGUMENTS:
  <results>               A run's results file, or the log folder in
                          <project>_muter_logs of any of the run's sessions.
                          Several, one for each shard of a run --shard split,
                          are merged into one report.

OPTIONS:
  -f, --format <format>   The report format: plain, json, html, xcode
  -o, --output <output>   Output file for the report to be saved.
  --fail-under <percent>  Exit with status 2 when the headline mutation score
                          is below this percent, from 0 to 100, once the report
                          is written. For a run, in place of failUnder.
  --property-tests <glob> Split the report's kills between example tests and
                          the property tests this glob matches by name or by
                          the file their issue was recorded in; * matches any
                          characters. Repeatable. In place of propertyTests.
  --force-merge           Merge shards' results although their SwiftMutator
                          build, toolchain or SDK differ. With one file, it
                          does nothing.
  --merge-ignoring <glob> Merge shards' results although project files matching
                          this glob differ between them; * also matches /.
                          Repeatable. With one file, it does nothing.
  --summary <path>        Also save the run's summary.json, its score, counts
                          and details for scripts, at this path.
  --triage <path>         Show the labels in this triage file, if not
                          muter.triage.yml in the run's project, or in the
                          current folder.
  --version               Show the version.
  -h, --help              Show help information.
