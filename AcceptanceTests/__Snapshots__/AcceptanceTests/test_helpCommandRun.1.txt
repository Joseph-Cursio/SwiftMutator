OVERVIEW: Performs mutation testing for the Swift project contained within the
current directory.

USAGE: swift-mutator run <options>

OPTIONS:
  --files-to-mutate <files-to-mutate>
                          Only mutate a given list of source code files.
  --operators <operators> The list of mutant operators to be used:
                          RelationalOperatorReplacement, RemoveSideEffects,
                          ChangeLogicalConnector, SwapTernary
  --since <ref>           Only mutate the Swift files changed since the merge
                          base of this git ref and HEAD: committed,
                          uncommitted, and new files git doesn't ignore. The
                          excludes and the coverage filter still apply.
  --changed-lines         With --since, only mutate code on the lines the
                          change added or changed.
  --shard <k/n>           Only test shard k of n, such as 1/2: n runs, on as
                          many machines, test each mutant once between them. A
                          mutant's shard follows from where it is.
                          swift-mutator report merges their results files.
  --sample <N>            Only test a sample of about N of the mutants
                          discovered, as for a trend between whole runs. The
                          reports give how far the score may be from a whole
                          run's.
  --seed <S>              With --sample, the seed that chooses the sample: the
                          same seed chooses the same mutants anywhere. Without
                          it, SwiftMutator chooses one and says which.
  --mutant <mutant>       Test only this mutant, and print its change, its
                          tests' log and its verdict: path:line[:column]
                          [Operator], as the progress lines and reports name
                          it, such as 'Bar.swift:12:9' or
                          'Sources/Foo/Bar.swift:12:9 SwapTernary'.
  -c, --configuration <configuration>
                          The path to the configuration file.
  --skip-coverage         Skips the step in which SwiftMutator runs your
                          project in order to filter out files without coverage.
  --skip-update-check     Skips the step in which SwiftMutator checks for newer
                          versions.
  --verbose               Lists how many mutants are in each file that has any,
                          and the Swift files found, if the command looks for
                          them.
  --workers <count>       How many mutants to test at once, in place of
                          mutationTestWorkers. Only SwiftPM projects test more
                          than one.
  --timeout <seconds>     Seconds before a mutant's test run is stopped, in
                          place of mutationTestTimeout. At most a day, 86400.
  -f, --format <format>   The report format: plain, json, html, xcode
  -o, --output <output>   Output file for the report to be saved.
  --resume <results>      Continue a stopped run from its results file, or the
                          log folder of any of its sessions. Only mutants
                          without a result that still holds are tested.
  --resume-ignoring <glob>
                          With --resume, reuse results although project files
                          matching this glob changed; * also matches /.
                          Repeatable.
  --force-resume          With --resume, reuse results although SwiftMutator,
                          the toolchain or the SDK changed.
  --reuse <results>       Start a new run from an earlier run's results file,
                          or the log folder of any of its sessions, finished or
                          not. Only mutants without a result that still holds
                          are tested, and the new run writes a results file of
                          its own.
  --reuse-ignoring <glob> With --reuse, reuse results although project files
                          matching this glob changed; * also matches /. Test
                          files are never waived. Repeatable.
  --force-reuse           With --reuse, reuse results although SwiftMutator,
                          the toolchain or the SDK changed.
  --version               Show the version.
  -h, --help              Show help information.
