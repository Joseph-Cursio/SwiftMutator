OVERVIEW: 🔎 Automated mutation testing for Swift, based on Muter 🕳️

USAGE: swift-mutator <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  init                    Creates the configuration file that SwiftMutator uses
  run (default)           Performs mutation testing for the Swift project in
                          the current folder, or in --project-folder's.
  run-without-mutating    Performs mutation testing using the test plan.
  mutate-without-running  Mutates the source code and outputs the test plan as
                          JSON.
  report                  Builds a report from a run's results file, or from
                          its shards' results files merged.
  triage                  Labels a surviving mutant in muter.triage.yml, which
                          the reports show. It changes no score.
  operator                Describes a given mutation operator.

  See 'swift-mutator help <subcommand>' for detailed help.
