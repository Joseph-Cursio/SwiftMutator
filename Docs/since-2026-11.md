# Measured: `run --since`

On 1 November 2026, for [#72](https://github.com/Joseph-Cursio/SwiftMutator/issues/72), `run --since` was run three times on SwiftProjectLint, against the full run of the same tree recorded on 31 October ([reuse-2026-10.md](reuse-2026-10.md)). Each scenario ran once, so read the times as indicative.

## Summary

- **A change to tests only: 1 s, nothing copied, exit 0.** `--since HEAD~1` is PR #266, which changed two test files. SwiftMutator said that the excludes leave out both, so there was nothing to mutate.
- **A four-file pull request: 2.7 min against 27.3 min for the whole project.** `--since HEAD~2` is PR #264 with PR #266 on top: 12 Swift files changed, 4 of them source files. Discovery kept those 4, and found 31 mutants in 3 of them, all of which the full run had too. The run took the copy, the baseline and 31 mutants, against 2,463.
- **The same by changed lines: 50 s, 1 mutant.** `--changed-lines` kept the one mutant on a changed line, `StateVariableVisitor.swift:298` (`==` to `!=`). The 14 other mutants in the 3 files are on lines the change didn't touch.
- **Every verdict matched the full run's.** All 31 mutants of the file-level run, and the one of the line-level run, had the full run's verdicts: 24 killed and 7 survived, and 1 survived.
